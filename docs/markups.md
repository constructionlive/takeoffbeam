# Markups

Markups are notes on the drawing rather than quantities. They show in the Markups List, export
into the flattened PDF, and the AI can add them too.

| Tool | Key | How |
|---|---|---|
| Text box | T | Drag a box (or click), then type. Double-click to edit later. |
| Callout | Q | Drag the text box, then click where the leader points. |
| Cloud | O | Click the corners; double-click to finish. Revision-cloud scallops. |
| Rectangle / Ellipse | R / E | Drag. |
| Line / Arrow | N / W | Drag from tail to head. |
| Polyline / Polygon | Y / J | Click points; double-click to finish. |
| Highlight | I | Drag over text. |
| Pen | D | Draw freehand. |
| Stamp | M | Drag a box: APPROVED, REVIEWED, REVISE, VERIFY IN FIELD, or your own text. |

## Legends

A **legend** is a box on the sheet listing the items with their swatch (color, line style or
hatch), name, count and total quantity with units. It updates as you take off and prints in the
flattened PDF. In the Takeoff tab, **Legends → Place**, then drag a box on the sheet (or click
for a default size).

Select a legend to move it, drag a corner to resize it (its text scales with the box), and set
its options in **Properties**:
- **Title** (default "Legend").
- **Lists** the items on *this page* or on *every page*, and optionally *markups too*, by
  subject.
- **Columns:** count, quantity and cost.
- **Items:** every item in scope, or only the ones you tick.

Items with nothing in scope, and hidden items, are left out.

With a markup tool active and nothing selected, the **Properties** tab sets that tool's defaults:
line color, width, opacity, line style, fill, font size and stamp text. Select a markup to change
its own style, subject and review status.
